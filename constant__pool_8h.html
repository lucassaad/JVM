Detailed Description

Estruturas e funções relacionadas ao Constant Pool de um arquivo .class.

Define todas as structs que representam os 17 tipos de entradas do constant pool, conforme a Java Virtual Machine Specification, além do enum de tags e das funções de leitura e validação do pool.

◆ cp_tags

typedef enum cp_tags cp_tags

Dicionário de tags usado pela JVM para identificar o tipo de constante lida.

Cada valor corresponde à tag que precede a entrada no arquivo .class. Tags 2, 13 e 14 não existem na especificação atual. Entradas do tipo Long (5) e Double (6) ocupam dois slots consecutivos no pool.

int check_constant_pool_references ( ClassFile *  cf)

Varre o Constant Pool e valida os índices internos de cada entrada.

Verifica se todos os índices cruzados (e.g. class_index aponta para CONSTANT_Class, name_index aponta para CONSTANT_Utf8) são válidos e apontam para o tipo correto.

Parameters
cfPonteiro para o ClassFile cujo constant pool será validado.
Returns
1 se todas as referências são válidas, 0 caso contrário.
