Detailed Description

Atributo Code — utilizado na estrutura de métodos.

Contém o bytecode executável de um método, junto com informações de tamanho da pilha de operandos, variáveis locais, tabela de exceções e sub-atributos de depuração. É o principal atributo consultado pelo interpretador.
