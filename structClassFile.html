Detailed Description

Estrutura principal do arquivo .class.

Representa o conteúdo completo de um arquivo .class Java carregado em memória, seguindo o formato definido pela Java Virtual Machine Specification. É preenchida pela função read_classfile() e consultada pelo viewer e pelo interpretador.
