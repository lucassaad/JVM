Detailed Description

Estrutura lógica de um array Java em tempo de execução.

Representa um array alocado dinamicamente. Para tipos de 64 bits (T_LONG e T_DOUBLE), o array elements contém o dobro de slots de 32 bits, pois cada elemento ocupa dois slots consecutivos (big-endian: índice par = high word, índice ímpar = low word). Para T_REFERENCE, cada elemento de elements armazena um ponteiro de 32 bits (ou índice) para o objeto referenciado.
