Detailed Description

Frame de execução da JVM.

Criado a cada invocação de método e destruído ao retornar. Contém o vetor de variáveis locais, a pilha de operandos, uma referência à constant pool da classe corrente, o bytecode do método e o program counter local. Frames são encadeados via previous_frame formando a call stack.
