Detailed Description

Estrutura e funções do Frame de execução da JVM.

Define o Frame — a unidade de execução empilhada na JVMStack a cada invocação de método — e todas as funções para criação, destruição, acesso às variáveis locais, manipulação da pilha de operandos e gerenciamento do ciclo de vida de chamada e retorno de métodos.

Cada slot do vetor de variáveis locais e da pilha de operandos possui 32 bits. Valores do tipo long e double ocupam 2 slots consecutivos (big-endian: o slot de índice mais baixo guarda os 32 bits mais significativos). A representação interna é uint32_t (bits crus); funções auxiliares fazem a conversão de/para int32_t, float, int64_t e double via memcpy.

Typedef Documentation

◆ Frame

typedef struct Frame Frame

Frame de execução da JVM.

Criado a cada invocação de método e destruído ao retornar. Contém o vetor de variáveis locais, a pilha de operandos, uma referência à constant pool da classe corrente, o bytecode do método e o program counter local. Frames são encadeados via previous_frame formando a call stack.

enum ReturnType

Tipos de retorno de método.

Usado por frame_pop_method() para determinar quantos slots copiar e como interpretar o valor de retorno ao restaurar o frame chamador.

Enumerator
RETURN_VOID 

Método void (return): nenhum valor é empilhado no chamador.

RETURN_INT 

ireturn: retorno int, boolean, byte, char ou short (1 slot).

RETURN_FLOAT 

freturn: retorno float (1 slot).

RETURN_LONG 

lreturn: retorno long (2 slots).

RETURN_DOUBLE 

dreturn: retorno double (2 slots).

RETURN_REF 

areturn: retorno de referência a objeto ou array (1 slot).

Conta o número de slots de 32 bits ocupados pelos argumentos de um método.

Percorre o descritor de método (e.g. "(ILjava/lang/String;D)V") e soma os slots de cada parâmetro: primitivos de 32 bits = 1 slot, long/double = 2 slots, tipos referência = 1 slot. O tipo de retorno (após )) é ignorado.

Parameters
method_descriptorString do descritor de método lida da constant pool.
is_instance_method1 para métodos de instância (adiciona +1 slot para this), 0 para estáticos.
Returns
Número total de slots de variáveis locais necessários para os argumentos.

Realiza o término normal de um método e restaura o frame chamador.

Lê o valor de retorno do topo da pilha de operandos do frame atual (se return_type != RETURN_VOID), desempilha e libera o frame atual da JVMStack, e empilha o valor de retorno na pilha de operandos do frame chamador restaurado.

Parameters
stackPonteiro para a JVMStack.
return_typeTipo do valor de retorno, que determina quantos slots copiar.
Returns
1 se ainda restar um frame corrente (execução continua no chamador), 0 se a pilha ficou vazia (método finalizado era o inicial).

JVMStackStatus frame_push_method ( JVMStack *  stack,
Code_attribute *  code_attr,
cp_info **  constant_pool,
uint16_t  constant_pool_count,
uint16_t  num_arg_slots 
)

Cria e empilha um novo Frame na JVMStack para invocar um método.

Aloca o novo Frame com base no atributo Code, transfere os num_arg_slots argumentos do topo da pilha de operandos do frame chamador para as variáveis locais do novo frame (índices 0..num_arg_slots-1, preservando a ordem), empilha o novo frame e atualiza o PC.

Parameters
stackPonteiro para a JVMStack.
code_attrAtributo Code do método a ser invocado.
constant_poolConstant pool da classe do método.
constant_pool_countNúmero de entradas da constant pool.
num_arg_slotsNúmero de slots de argumentos a transferir do chamador.
Returns
Status da operação: JVM_STACK_OK, JVM_STACK_OVERFLOW_ERROR ou JVM_STACK_OUT_OF_MEMORY.
