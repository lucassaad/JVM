Detailed Description

Implementação do Frame de execução da JVM.

Implementa a criação, destruição, acesso a variáveis locais, manipulação da pilha de operandos e o ciclo de vida de chamada/retorno de métodos.

Convenções de implementação:

  • Todos os valores são armazenados como slots de 32 bits (uint32_t). memcpy é usado em vez de cast para copiar bits sem reinterpretação de sinal ou tipo (evita undefined behavior em conversões de ponteiro).
  • Valores de 64 bits (long, double) ocupam 2 slots consecutivos em big-endian: slot[index] = high 32 bits, slot[index+1] = low 32 bits.
  • frame_push_raw / frame_pop_raw são as primitivas base; todas as outras funções de push/pop delegam a elas após converter o tipo para/de uint32_t via memcpy.
  • frame_push_method transfere os argumentos diretamente do array operand_stack do chamador para o array local_vars do novo frame (sem pop/push individuais), ajustando o SP do chamador ao final.
  • frame_pop_method lê o valor de retorno antes de destruir o frame corrente, depois o empilha no frame restaurado (chamador).

Conta o número de slots de 32 bits ocupados pelos argumentos de um método.

Percorre o descritor de método (e.g. "(ILjava/lang/String;D)V") e soma os slots de cada parâmetro: primitivos de 32 bits = 1 slot, long/double = 2 slots, tipos referência = 1 slot. O tipo de retorno (após )) é ignorado.

Parameters
method_descriptorString do descritor de método lida da constant pool.
is_instance_method1 para métodos de instância (adiciona +1 slot para this), 0 para estáticos.
Returns
Número total de slots de variáveis locais necessários para os argumentos.

JVMStackStatus frame_push_method ( JVMStack *  stack,
Code_attribute *  code_attr,
cp_info **  constant_pool,

)

Cria e empilha um novo Frame na JVMStack para invocar um método.

Aloca o novo Frame com base no atributo Code, transfere os num_arg_slots argumentos do topo da pilha de operandos do frame chamador para as variáveis locais do novo frame (índices 0..num_arg_slots-1, preservando a ordem), empilha o novo frame e atualiza o PC.

Parameters
stackPonteiro para a JVMStack.
code_attrAtributo Code do método a ser invocado.
constant_poolConstant pool da classe do método.
constant_pool_countNúmero de entradas da constant pool.
num_arg_slotsNúmero de slots de argumentos a transferir do chamador.
Returns
Status da operação: JVM_STACK_OK, JVM_STACK_OVERFLOW_ERROR ou JVM_STACK_OUT_OF_MEMORY.
