Detailed Description

Estrutura lógica de um objeto Java em tempo de execução.

Representa uma instância de classe alocada dinamicamente. O vetor fields armazena os campos de instância (não estáticos) na ordem de declaração da classe, usando slots de 32 bits. Campos do tipo long e double ocupam dois slots consecutivos.
